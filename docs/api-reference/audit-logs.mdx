# Audit Logs

The audit log records every sensitive action in the system. Entries are append-only; they cannot be edited or deleted via the API.

---

## GET /api/audit-logs

List audit log entries for the caller's hospital.

**Roles:** super_admin, admin, doctor

**Query params**

| Param | Type | Default | Description |
|---|---|---|---|
| `page` | int | 1 | Page number |
| `per_page` | int | 20 | Results per page |
| `action` | string | — | Filter by action type |
| `patient_id` | int | — | Filter by patient |
| `staff_id` | int | — | Filter by staff member |

**Response 200**

```json
{
  "data": [
    {
      "id": 500,
      "staff_id": 5,
      "hospital_id": 2,
      "action": "fingerprint_lock",
      "patient_id": 42,

      "user_agent": "Dart/3.0 (dart:io)",
      "meta": {
        "fingerprint_id": 7,
        "failed_attempts": 5,
        "window_hours": 1
      },
      "created_at": "2025-05-01T15:05:00Z"
    }

  "current_page": 1,

```

## Action types

| Action | Trigger |
|---|---|
| `login_success` | Staff logged in |
| `login_failed` | Failed login attempt |
| `patient_create` | New patient registered |
| `patient_update` | Patient demographics edited (directly, or via an approved edit request) |
| `patient_delete` | Patient soft-deactivated |
| `fingerprint_enroll` | Fingerprint (or hand) template stored |
| `fingerprint_delete` | Fingerprint record deactivated |
| `fingerprint_match` | Hospital-wide fingerprint identification returned a match |
| `fingerprint_no_match` | Verification returned NO MATCH |
| `fingerprint_lock` | Record locked after repeated failures |
| `fingerprint_unlock` | Admin unlocked a record |
| `face_enroll` | Face template stored |
| `face_match` / `face_no_match` | Face identification result |
| `face_manual_confirm` | Staff manually confirmed a `needs_review` face result |
| `edit_request_submitted` | Nurse submitted a demographic edit request |
| `edit_request_approved` | Admin approved an edit request |
| `edit_request_rejected` | Admin rejected an edit request |
| `edit_request_cancelled` | Nurse cancelled their own pending request |
| `visit_open` / `visit_close` / `visit_reopen` | Visit lifecycle transitions |
| `stage_verified` | A visit stage's biometric verification succeeded |
| `stage_override_requested` | Staff requested a supervisor override for a failed stage verification |
| `stage_override_resolved` | Supervisor approved or denied an override request |
| `access_restricted` | A biometric identification resolved a patient the caller's hospital isn't authorized to see |
| `hospital_created` / `hospital_updated` / `hospital_deactivated` | Hospital configuration changes |
| `user_created` / `user_updated` / `user_deactivated` | Staff account lifecycle |
| `ehr_access` / `insurance_check` | GoT-HoMIS EHR/insurance lookup on a successful match |
| `manual_override` | Reserved constant for manual verification overrides |

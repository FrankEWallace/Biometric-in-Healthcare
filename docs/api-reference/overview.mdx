# API Overview

**Base URL:** `https://fyp.fwtechnologies.co.tz/api` (local development: `http://localhost:8000/api`)

All endpoints consume and produce `application/json` unless the request involves a file upload, in which case `multipart/form-data` is used.

## Authentication

All routes except `POST /auth/login` require a Sanctum bearer token:

```http
Authorization: Bearer 1|abc123...
```

Tokens are issued by `POST /auth/login`, expire after 8 hours, and are revoked on logout.

## Standard error format

```json
{
  "error": "Human-readable message.",
  "hint": "Optional: what to do instead."
}
```

Validation errors follow Laravel's default format:

```json
{
  "message": "The given data was invalid.",
  "errors": {
    "field_name": ["Validation error message."]
  }
}
```

## Common HTTP status codes

| Code | Meaning |
|---|---|
| 200 | Success |
| 201 | Resource created |
| 400 | Bad request |
| 401 | Unauthenticated (missing or expired token) |
| 403 | Forbidden (wrong role, IP outside hospital's allowed range, geofence failure, or self-approval on a supervisor override) |
| 404 | Not found (or cross-hospital access blocked by policy) |
| 409 | Conflict (e.g. unlocking a record that is not locked, visit already open/closed, duplicate pending edit request) |
| 410 | Gone (edit request expired) |
| 422 | Validation failed, fingerprint/face quality too low, liveness check failed, or too few usable fingers in a hand capture |
| 423 | Fingerprint record is locked |
| 503 | Python biometric service unavailable |

## Roles

The system has **seven** roles: `super_admin`, `admin`, `doctor`, `nurse`, `clerk`, `lab_technician`, `pharmacist`. See the full [RBAC matrix](/rbac) for the per-endpoint breakdown.

## Rate limits

| Route group | Limit |
|---|---|
| `POST /auth/login` | 10 req / min per IP |
| Fingerprint/face/hand enroll routes | 20 req / min per token |
| Fingerprint/face/hand/multimodal verify routes | 30 req / min per token |
| `POST /fingerprint/liveness-check` | 60 req / min per token |
| `POST /face/rebuild-index` | 5 req / min per token |
| `POST /visits/{visit}/stages/{stage}/verify` | 30 req / min per token |

## Pagination

List endpoints return paginated results:

```json
{
  "data": [...],
  "current_page": 1,
  "per_page": 20,
  "total": 150,
  "last_page": 8
}
```

Pass `?per_page=50` to change page size.

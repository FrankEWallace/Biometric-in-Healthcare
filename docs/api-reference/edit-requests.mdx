# Edit Requests

Nurses cannot edit patient demographics directly (`PUT /api/patients/{patient}` is restricted to admin/super_admin). Instead they submit a **single-field** edit request that an admin or super_admin reviews and approves or rejects.

<Note>
  Each request changes exactly **one** field. To change multiple fields, submit multiple requests. This keeps the audit trail unambiguous about what was proposed, by whom, and why, per field.
</Note>

---

## POST /api/patients/{patient}/edit-requests

Submit a demographic edit request for one field.

**Roles:** nurse

**Request body**

```json
{
  "field_name": "phone",
  "new_value": "+255 61 999 000",
  "reason": "Patient reported a new phone number at this visit."
}
```

| Field | Type | Required | Notes |
|---|---|---|---|
| `field_name` | enum | Yes | One of `full_name`, `phone`, `date_of_birth`, `gender` |
| `new_value` | string | Yes | Max 200 chars |
| `reason` | string | Yes | Min 10, max 500 chars |

**Response 201**

```json
{
  "edit_request": {
    "id": 12,
    "patient_id": 42,
    "hospital_id": 2,
    "requested_by": 5,
    "field_name": "phone",
    "old_value": "+255 61 123 456",
    "new_value": "+255 61 999 000",
    "reason": "Patient reported a new phone number at this visit.",
    "status": "pending",
    "expires_at": "2026-05-08T10:00:00Z",
    "created_at": "2026-05-01T10:00:00Z"
  }
}
```

**Response 422:** new value equals current value

```json
{ "error": "New value is the same as the current value." }
```

**Response 409:** a pending request for this field already exists

```json
{ "error": "A pending request for this field already exists." }
```

## GET /api/edit-requests

List pending edit requests for the caller's hospital (super_admin sees all hospitals).

**Roles:** admin, super_admin

**Response 200:** paginated list of edit request objects, ordered oldest-first, each with `patient` (id, full_name) and `requestedBy` (id, name) loaded.

---

## PUT /api/edit-requests/{editRequest}/approve

Approve an edit request. The patient's `field_name` is updated immediately.

**Roles:** admin, super_admin

**Response 200**

```json
{
  "message": "Request approved.",
  "edit_request": { "...": "...", "status": "approved" }
}
```

**Response 409:** request is no longer pending

**Response 410:** request has expired

```json
{ "error": "Request has expired." }
```

Approving writes both `edit_request_approved` and `patient_update` audit log entries.

---

## PUT /api/edit-requests/{editRequest}/reject

Reject a pending edit request.

**Roles:** admin, super_admin

**Response 200**

```json
{
  "message": "Request rejected.",
  "edit_request": { "...": "...", "status": "rejected" }
}
```

**Response 409:** request is no longer pending

---

## PUT /api/edit-requests/{editRequest}/cancel

Cancel a pending edit request. Enforced by `PatientEditRequestPolicy::cancel`: only the nurse who submitted it can cancel it, and only while it is still `pending`.

**Roles:** nurse

**Response 200**

```json
{ "message": "Request cancelled." }
```

# Getting started

The system has three independently deployable components. You can run them all on one machine during development.

## Prerequisites

| Tool | Version | Used by |
|---|---|---|
| PHP | 8.3+ | Laravel 13 backend |
| Composer | 2.x | Laravel dependencies |
| MySQL | 8.0+ | Database |
| Node.js | 18+ | Asset compilation (Laravel), Web Admin (Next.js) |
| Python | 3.10+ (service Dockerfile uses 3.13) | Biometric processing service |
| pip | 23+ | Python dependencies (FastAPI, OpenCV, SourceAFIS-style matching, ONNX Runtime, InsightFace, FAISS) |
| Flutter SDK | 3.11+ | Mobile app |
| Android Studio / Xcode | Latest | Mobile emulator or device |

## Quick-start order

<Steps>
  <Step title="Start the Python service">
    The Laravel backend calls the Python service synchronously, so start it first.
    See [Python Service Setup](/getting-started/python-service).
  </Step>
  <Step title="Start the Laravel backend">
    Configure `.env`, run migrations, and serve the API.
    See [Backend Setup](/getting-started/backend).
  </Step>
  <Step title="Run the Flutter app">
    Point the app at your local Laravel URL and launch on an emulator or device.
    See [Mobile Setup](/getting-started/mobile).
  </Step>
  <Step title="(Optional) Run the web admin dashboard">
    Next.js app for hospital/staff administration. `cd web-admin && npm install && npm run dev` runs on `http://localhost:3000`. See `docs/dev-commands.md` in the repository for the full local-stack reference.
  </Step>
</Steps>

## Ports (default)

| Service | Port |
|---|---|
| Laravel (php artisan serve) | `8000` |
| Python biometric service | `5001` |
| Web Admin (Next.js dev server) | `3000` |
| MySQL | `3306` |
| MAMP (if used) | `8888` |

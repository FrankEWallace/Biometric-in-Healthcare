# Python Service Setup

The fingerprint microservice is a FastAPI app that handles all image processing. It is called internally by Laravel and is **not** exposed to the public internet.

## 1. Create a virtual environment

```bash
cd python-service
python3 -m venv venv
source venv/bin/activate   # Windows: venv\Scripts\activate
```

## 2. Install dependencies

```bash
pip install -r requirements.txt
```

Core dependencies:

| Package | Purpose |
|---|---|
| `fastapi` | HTTP framework |
| `uvicorn` | ASGI server |
| `opencv-python` | Image preprocessing (CLAHE, Gabor, morphology) |
| `numpy` | Array operations |
| `faiss-cpu` | FAISS face index (enroll, identify, rebuild) |
| `pydantic` | Request/response validation |

## 3. Configure the internal API key (optional locally, required in production)

Create `python-service/.env` (no example file is checked in yet — this repo doesn't ship a `python-service/.env.example`):

```dotenv
# Must match PYTHON_SERVICE_API_KEY on the Laravel side. Left unset locally
# is fine — a warning is logged and every endpoint except /health accepts
# unauthenticated requests. Set it before deploying anywhere reachable
# beyond your own machine.
INTERNAL_API_KEY=

FINGERPRINT_MATCH_THRESHOLD=32.0
ENVIRONMENT=development   # set to "production" to disable /docs and /redoc
```

## 4. Place the contactless embedding model

The four-finger contactless matcher needs an ONNX model at `models/contactless_embedding.onnx` (~1.1GB, gitignored — not part of the repo). Without it, the contactless matcher falls back to the non-discriminative minutiae path and `/process-hand`/`/match-hand` responses report the fallback matcher name.

## 5. Run the service

```bash
python run.py
# or
uvicorn app.main:app --host 0.0.0.0 --port 5001 --reload
```

The service starts on `http://localhost:5001`.

## 6. Verify it is running

```bash
curl http://localhost:5001/health
# {"status": "ok"}
```

## Interactive API docs

Swagger UI and ReDoc are available during development:

- Swagger UI: `http://localhost:5001/docs`
- ReDoc: `http://localhost:5001/redoc`

## Service structure

```
python-service/
├── run.py                          ← entry point (uvicorn launcher)
├── quarantine/                     ← corrupt FAISS index backups (auto-created)
└── app/
    ├── main.py                     ← FastAPI app, router registration
    ├── routes/
    │   ├── health.py               ← GET /health
    │   ├── fingerprint.py          ← POST /process, /match, /process-fingerprint, /match-fingerprint
    │   ├── hand.py                 ← POST /process-hand, /match-hand (four-finger contactless)
    │   └── face.py                 ← POST /face/process, /face/match, /face/enroll, /face/identify
    └── services/
        ├── processor.py            ← build_template(), match_templates()
        ├── image_processor.py      ← preprocess_fingerprint() pipeline
        ├── feature_extractor.py    ← extract_features(), match_features()
        ├── hand_segmentation.py    ← segment_hand() — whole-hand photo → 4 finger crops
        ├── matcher.py              ← domain-routed matcher selection + match_hands() fusion
        ├── embedding_service.py    ← ONNX Ridgeformer embedding matcher (contactless)
        ├── faiss_service.py        ← FAISS index (enroll, identify with retry, rebuild, quarantine)
        ├── liveness_service.py     ← anti-spoofing checks (env-configurable thresholds)
        ├── minutiae_service.py     ← crossing-number minutiae algorithm
        └── sourceafis_service.py   ← template extraction/matching API (wraps minutiae_service)
```

## Processing pipeline

Each fingerprint image passes through these steps before feature extraction:

```
Raw image (JPEG/PNG)
      │
      ▼ Grayscale conversion
      ▼ Gaussian blur (noise reduction)
      ▼ Histogram equalization (contrast normalisation)
      ▼ Adaptive thresholding (binarisation)
      ▼ Morphological thinning (skeleton extraction)
      │
      ▼ ORB keypoint detection
      ▼ BRIEF descriptor computation
      │
      └─► feature template  (keypoints + descriptors as JSON)
```

<Note>
  Every route except `/health` is protected by `require_internal_key` when `INTERNAL_API_KEY` is set — Laravel sends it as `X-Internal-Api-Key`. If unset (default for local dev), the check is skipped and a warning is logged; set it before this service is reachable from anywhere beyond your own machine.
</Note>
